# سوق النِّسَب 🐪

درس تفاعلي في **المعادلة المئوية** (رياضيات ثاني متوسط – الفصل الرابع: النسبة المئوية).

الطالب يتجوّل في سوق، ويسولف مع البيّاعين، ويحسب الخصومات والأرباح والخسائر، ويجمع النجوم، وفي النهاية يطلع له شهادة.

- ٧ محطات: معنى ٪ والقانون ج = ن × ك، إيجاد الجزء، إيجاد النسبة، إيجاد الكل، الربح والخسارة، فخ «زاد ثم نقص»، ومسابقة نهائية
- ملخص للدرس مع المثلث السحري
- آلة حل تشرح أي مسألة خطوة بخطوة
- يشتغل على أي جوال، والموقع كله ملف واحد (`index.html`)
